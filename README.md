# ZeekData24 Model Training and Testing
Source code for the research paper entitled:
**Exploratory Data Analysis of UWF-ZeekData24 using Supervised Machine Learning and Deep Learning Techniques**

# Datasets
1st_Iteration: Datasets made in NSTHES2, includes 15k MC, SMOTEN MC, Compiled Binary

2st_Iteration: Datasets revised in NSTHES3 include the usage of different iterations of ZeekData24 which are ZeekData24Fall and ZeekData22Fall.  

# Models
CTTHES2: Models Made in NSTHES2 including different hyperparameter tuning

CTTHES3: Models revised in NSTHES3 include readjustment of gridsearch parameters, standardization of matplt visualization results, and integration with google colab for faster training.
